# ADS Gamepad Documentation

This package installs the documentation of the ADS Gamepad Service under C:\Program Files\Beckhoff USA Community\ADS Gamepad\Documentation: the project overview, the configuration reference of the Windows service, the migration guide from the XboxControllerUtilities library, and the TcCOM module description.

The current version of every document also lives in the project repository: https://github.com/Beckhoff-USA-Community/ADS-Gamepad-Service
