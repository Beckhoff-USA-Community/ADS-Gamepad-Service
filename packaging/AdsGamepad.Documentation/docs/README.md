# ADS Gamepad Documentation

This package installs the documentation of the ADS Gamepad Service under C:\Program Files\Beckhoff USA Community\ADS Gamepad\Documentation: the project overview, the configuration reference, the migration guide from the XboxControllerUtilities library, the TcCOM module description, and the full documentation site pages in the site folder, covering installation on Windows and Beckhoff RT Linux, the PLC library, and the wire contract.

The current version of every document also lives in the project repository: https://github.com/Beckhoff-USA-Community/ADS-Gamepad-Service
