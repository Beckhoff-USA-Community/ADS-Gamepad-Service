# ADS Gamepad Engineering Workload

This workload sets up an engineering system for the ADS Gamepad Service through its dependency packages: the AdsGamepad PLC library, the documentation, and the source of the TcCOM module. The library is installed into the XAE library repository, ready to reference. The files land under C:\Program Files\Beckhoff USA Community\ADS Gamepad.

The service itself runs on the runtime system and comes with the matching runtime workload, Beckhoff-USA-Community.AdsGamepad.XAR.

Project home, documentation, and the PLC library: https://github.com/Beckhoff-USA-Community/ADS-Gamepad-Service
